## Open the current demo
Open `customer/index.html` for the customer frontend and `admin/index.html` for the admin panel.

For local HTTP preview (recommended), run from this folder:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000/customer/` or `http://localhost:8000/admin/`.

## Use in Codex
Create a **private GitHub repository** for this project and upload/commit these source files, then select that repository in Codex. Alternatively open this folder in an environment that supports Codex.
